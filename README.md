#stm32项目关于工厂流水线模拟的开发
我的嵌入式学习硬件：蓝板stm32f103c8t6，stlinkv2 usb转ttl（ch340）数据线 杜邦线 
软件下载：stm32cubemx用于负责配置硬件 keil5用于编译写代码下载代码 sscom.5(串口助手)
代码方面：mdk-arm
简单的网页：index。html 
本工厂流水线模拟，采用超级循环+状态机+非阻塞轮询
超级循环：主要是用了while(1),转着圈循环着整个代码
状态机：（idle——feed——process——check——sort）每两秒自动切换
非阻塞轮询：采用hal gettick非阻塞类似于秒表的东西，判断有关状态的时间到没，即使没有到，依旧会跳着转着圈继续着，并没有用到hal delary阻塞，因此CPU也不会被卡死，LED的闪烁，和本身的状态依旧继续着
本流水线模拟也运用到了优先级及其反转
